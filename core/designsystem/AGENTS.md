# Core Designsystem Module - AGENTS.md

`core/designsystem` provides shared Compose UI tokens and components.

## Keep In Mind

- Reuse existing design tokens and components before creating new ones.
- Keep components reusable and presentation-only.
- Preserve the established visual language and accessibility behavior.
- Do not put feature logic or navigation here.

## Focus Areas

- Colors, typography, spacing, shapes (`theme/Color.kt`, `theme/Type.kt`, `theme/Shape.kt`)
- Theme: `KoinTheme` in `theme/Theme.kt`
